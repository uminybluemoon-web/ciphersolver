タブの足し方

今回の暗号解読に限らず、同じページにツールを増やせます。GitHub に push すると公開サイトも更新されます。

1. ページを作る

docs/tools/_template.html をコピーして、例えば docs/tools/memo.html を作ります。

2. カタログに1行足す

編集するのは docs/js/catalog.js だけです。

window.SITE_TABS = [
  { id: "cipher", title: "暗号解読", file: "tools/cipher/index.html" },
  { id: "memo", title: "メモ", file: "tools/memo.html" },
  { id: "about", title: "タブの足し方", file: "tools/about.html" },
];
  • id … URL の #memo になります（英数字）
  • title … 上のタブに出る名前
  • file … HTML の場所（docs/ からの相対パス）

3. 公開を更新する

git add docs
git commit -m "メモタブを追加"
git push

GitHub の Settings → Pages で main の /docs を公開先にします。
